1 Манифест

Зачем этот хаб

Я разделяю философию Жака Фреско. Из неё главное для меня — знание и инструменты должны быть свободными. Не товаром, не подпиской, не сервисом, который однажды закроется.

Этот хаб — мой вклад. Здесь библиотека фильмов и цитат, карта концепций и мастерская для активистов. Всё в одном файле, всё работает офлайн. Открыл — работает. Через десять лет откроется так же.

Ничего не требует. Ни регистрации, ни оплаты, ни почты. Если пригодится — пользуйтесь. Если нет — просто закройте.

Принцип. Файл работает полностью автономно. Ни одного запроса в сеть. Ни одной аналитики. Ни одного трекера. Проверяется в инструментах разработчика любого браузера.
