1 Манифест

Зачем этот хаб

Этот файл собран для тех, кому близка философия Жака Фреско. Из неё главное — знание и инструменты должны быть свободными. Не товаром, не подпиской, не сервисом, который однажды закроется.

Здесь библиотека фильмов и цитат, карта концепций и мастерская для активистов. Всё в одном файле, всё работает офлайн. Открыл — работает. Через десять лет откроется так же.

Ничего не требует. Ни регистрации, ни оплаты, ни почты. Если пригодится — пользуйтесь. Если нет — просто закройте.

Принцип. Файл работает полностью автономно. Ни одного запроса в сеть. Ни одной аналитики. Ни одного трекера. Проверяется в инструментах разработчика любого браузера.

7 Принципы файла

Как устроен этот хаб

Один файл. HTML, CSS и JavaScript внутри одного документа. Никаких внешних библиотек, шрифтов, CDN.

Офлайн. Ни одного сетевого запроса. Проверяется в DevTools → Network: при работе с файлом — ноль обращений наружу. Внешние ссылки в разделе «Ресурсы» открываются только по вашему клику.

Без слежки. Ни аналитики, ни трекеров, ни куки. Данные, которые вы вводите в мастерской, сохраняются только в localStorage вашего браузера.

Без регистрации. Ничего не требует. Открывается двойным кликом.

Самопроверка. При открытии файл прогоняет внутренние тесты и показывает результат внизу. Если тесты не проходят — что-то пошло не так с файлом.

Свободно. Пользуйтесь, копируйте, передавайте дальше. Никаких условий.
