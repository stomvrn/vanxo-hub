# Проектирование Будущего · Офлайн-хаб

Независимый информационный хаб, посвящённый идеям
ресурсо-ориентированной экономики и философии Жака Фреско.

**Один файл. Работает офлайн. Ничего не отправляет наружу.**

## Что внутри

- Библиотека фильмов о проекте «Венера»
- Цитаты Жака Фреско
- Карта знаний: 8 ключевых концепций
- Мастерская активиста: генератор постов, планировщик, заметки
- Ссылки на официальные ресурсы

## Как использовать

1. Скачай `index.html`
2. Открой двойным кликом в браузере
3. Работает без интернета, без регистрации, без установки

## Технические детали

- CSP: `default-src 'none'; connect-src 'none'` — ноль сетевых запросов
- ES2015 и ниже — совместимость со старыми браузерами
- Self-check при открытии — 8 внутренних тестов
