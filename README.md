# VanXo · Проектирование Будущего

Офлайн-хаб для сообщества «Проектирование Будущего». Один файл, работает без интернета.

## Что внутри

- **Манифест** — коротко о принципах
- **Библиотека** — четыре главных фильма о Фреско с описаниями, книга, цитаты
- **Карта знаний** — восемь ключевых концепций: кликаешь — читаешь пояснение
- **Мастерская активиста** — генератор постов для соцсетей, планировщик событий, заметки
- **Список проектов** — офлайн-инструменты, которые уже сделаны

## Как использовать

1. Скачай файл `vanxo-hub.html`
2. Открой двойным кликом в любом браузере
3. Всё. Никаких установок, регистраций, настроек

Работает через десять лет так же, как сегодня. Всё сохраняется локально.

## Принципы

- **Офлайн-первый.** Работает без сети. Совсем.
- **Ноль зависимостей.** Один HTML-файл. Ни библиотек, ни фреймворков.
- **Ноль слежки.** Никаких запросов наружу. Проверяется в инструментах разработчика.
- **Ноль аккаунтов.** Ничего не требует. Открыл — работает.

## Лицензия

Свободное использование. Копируй, меняй, распространяй.
